# Migrating to Karni 0.4 (unreleased)

This page grows as 0.4 is built. Nothing below breaks a 0.3 project.

## Deprecated in 0.4

### The 0.3 colour token names

Every visual value in `@karni/ui` now resolves from a token in one of the
families `--karni-color-*`, `--karni-space-*`, `--karni-radius-*`,
`--karni-font-*` and `--karni-shadow-*` (see the
[styling section](https://github.com/cbsshekhawat18-lab/karni/tree/main/packages/karni-ui#styling)
of the @karni/ui README).

Colours are now plain CSS colours: `--karni-color-primary: oklch(0.55 0.22 285)`
or `var(--your-primary)`. The 0.3 names held HSL triplets
(`--karni-primary: 262 83% 58%`). Each `--karni-color-*` defaults to `hsl()` of
its 0.3 name, so a 0.3 theme keeps working unchanged. The 0.3 names are
deprecated in 0.4 and removed in 1.0.

To move a theme, rename each property and wrap the triplet in `hsl()`:

```css
/* 0.3 */
:root { --karni-primary: 262 83% 58%; }

/* 0.4 */
:root { --karni-color-primary: hsl(262 83% 58%); }
```

The renamed properties are `background`, `foreground`, `card`,
`card-foreground`, `popover`, `popover-foreground`, `primary`,
`primary-foreground`, `secondary`, `secondary-foreground`, `muted`,
`muted-foreground`, `accent`, `accent-foreground`, `destructive`,
`destructive-foreground`, `border`, `input`, `ring` and `chart-1` to `chart-5`:
`--karni-<name>` becomes `--karni-color-<name>`. `--karni-radius` keeps its
name; `--karni-radius-sm`, `-md`, `-lg` and `-xl` derive from it.

Opacity modifiers on Karni colours in your own code (`bg-primary/50`) keep
working under Tailwind 3 and 4. Inside `@karni/ui` they are replaced by named
shades (`bg-primary-hover`, `bg-muted-subtle`, `bg-destructive-subtle`), which
you can theme on their own.
