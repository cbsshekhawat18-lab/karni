From karni new to a running Django + React app

Declare a model and who may access it. The REST API, admin, permissions, React screens, tests and seed data come from the framework.

$ karni new "Ticket Shop" $ karni make model Event \ title:str:200 starts_at:datetime \ organizer:fk:User -a \ --access owned:organizer created frontend/src/pages/events.tsx created events/tests/test_event.py $ karni migrate && karni seed $ karni serve --local
Admin, no admin.py React app on @karni/ui
